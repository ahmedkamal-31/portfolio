## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/ahmedkamal-31/portfolio.git
```

Navigate to the project directory:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will then be available at the local development URL provided by Vite.

---

## 🏗️ Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run the linter:

```bash
npm run lint
```
